Magic Number Box (Variables)

In coding, a variable is like a box that holds a number. You can store a number in the box and later change it.

Try the widget below. Watch how the number and code change when you click the buttons.

Number in the box:

0

Type a number, then click “Store in box”.

Code:

let box = 0;

What did we learn?

The box is our variable. The number inside it is the value.

First we create the variable: let box = 0;

When you click the buttons, the value changes. The code becomes let box = newNumber;. That’s how programs remember and update information!
